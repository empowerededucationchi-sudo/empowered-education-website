# Empowered Education Website

Official website for **Empowered Education**, a 501(c)(3) nonprofit advancing equity in learning through youth mentoring, AI literacy consulting, and curriculum development.

**empowerededucate.org** · Chicago, IL

## Pages

| Page | File | Description |
|------|------|-------------|
| Homepage | `index.html` | Mission, pillars, founder strip, audience CTAs |
| About | `about.html` | Founder bio, mission, history, values |
| Programs | `programs.html` | Bridge Mentoring, Capital Workshop |
| Consulting | `consulting.html` | 4 services with pricing |
| The Problem | `the-problem.html` | Research-grounded problem statement with citations |
| Shop | `shop.html` | Downloadable products + course licensing |
| Impact | `impact.html` | Theory of change, research, roadmap |
| Contact | `contact.html` | Segmented inquiry forms |

## Tech

Static HTML/CSS/JS — no build step required. Deploy directly to GitHub Pages, Netlify, or any static host.

To enable GitHub Pages: **Settings → Pages → Deploy from branch → main → / (root)**
