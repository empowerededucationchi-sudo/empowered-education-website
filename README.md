# Empowered Education Website

Official website for Empowered Education, a 501(c)(3) nonprofit advancing equity in learning through youth pipeline programs, AI literacy consulting, and curriculum development.

## Structure
- `index.html` — Homepage
- `pages/` — Inner pages (about, programs, consulting, the-problem, shop, impact, contact, events, resources)
- `css/main.css` — Main stylesheet
- `js/main.js` — Navigation and interactions

## Status
Active development. Pages being built incrementally.
